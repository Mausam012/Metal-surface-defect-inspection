# data/sample

No X-ray images are shipped with this project (licensing). Options:

1. `python scripts/make_synthetic_sample.py` creates a **synthetic** gray image (clearly NOT an X-ray, no defects) to test uploading and preprocessing.
2. Download radiographs from an authorized source (e.g. GDXray, see README "Dataset") and upload them through the app.

Do not commit or redistribute third-party dataset images.
