{{ project_title }}

METALVISION AI is an academic prototype built by a four-member team. It is a working inspection pipeline with model slots; it is not a validated inspection system.

Problem statement

Voids, cracks, porosity and inclusions inside metal sheets cannot be seen from the surface. Radiographic inspection reveals them, but reading X-ray images manually is slow, tiring and varies between inspectors.

Motivation

Computer-assisted screening can point inspectors to suspicious regions faster and more consistently, while the final decision stays with a qualified person.

Proposed solution

A local web application that accepts radiographs, prepares them with OpenCV, passes them to interchangeable deep-learning models, visualizes suspicious regions, keeps an inspection history, and produces a PDF report.

Objectives

  • Detect and localize cracks, voids, porosity and inclusions.
  • Compare four architectures on identical data and metrics.
  • Keep real AI output clearly separate from demonstration output.
  • Run offline on a student laptop.

System architecture

Browser · HTML, CSS, JavaScript, Bootstrap 5, Chart.js
Flask · routes and JSON API (app.py)
Image pipeline · validation, OpenCV preprocessing, overlays
Model interface · CNN, YOLO, U-Net, ResNet (one result schema)
SQLite · inspections · ReportLab · PDF reports

Technologies

Frontend: HTML5, CSS3, JavaScript, Bootstrap 5, Chart.js

Backend: Python, Flask, SQLite

Image processing: OpenCV, NumPy, Pillow

Machine learning: PyTorch, Torchvision, scikit-learn

Reports and plots: ReportLab, Matplotlib

Four ML architectures

CNN
Learns local features with stacked convolutions. Classifies the whole image.
YOLO
Single-pass detector that outputs bounding boxes and labels.
U-Net
Encoder-decoder with skip connections for pixel-level masks.
ResNet
A CNN family with skip connections, y = F(x) + x. Strong base for transfer learning.

Expected outcomes

  • A reproducible pipeline from raw radiograph to reviewed report.
  • A fair comparison of four architectures once trained.
  • Documentation of dataset limits.

Research limitations

  • No trained models are included, so no performance is claimed.
  • Public casting and welding radiographs differ from flat sheets in geometry and appearance, so results on them do not transfer automatically.
  • Expert-reviewed sheet annotations are needed for any real validation.
  • Grad-CAM shows evidence, not defect outlines.

Future scope

  • Collect authorized flat-sheet X-rays with expert labels.
  • Group-aware training and independent test sets.
  • Model calibration and threshold tuning.
  • Ensemble or comparison dashboard across all four models.
